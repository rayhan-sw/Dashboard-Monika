ABSTRAK 
Pengelolaan data log aktivitas pengguna pada sistem BIDICS di lingkungan Badan 
Pemeriksa Keuangan (BPK) Republik Indonesia sebelumnya masih berupa data tekstual 
mentah tanpa dukungan visualisasi analitik. Kondisi tersebut mengakibatkan proses 
pemantauan operasional, identifikasi pola trafik, serta deteksi anomali berjalan kurang 
efisien karena sangat bergantung pada analisis manual. Selain itu, ketiadaan data 
pembanding pemanfaatan dashboard yang terstruktur menyebabkan proses optimalisasi 
dan pengambilan keputusan manajerial belum sepenuhnya berbasis pada data yang terukur. 
Sebagai solusi teknis, dikembangkan produk MONIKA (Monitoring Kluster Analitik), 
sebuah sistem single view dashboard terpusat yang dirancang untuk mengagregasi dan 
memvisualisasikan jutaan baris data log interaksi pengguna menjadi informasi strategis 
yang dinamis. Pengembangan perangkat lunak ini diimplementasikan menggunakan 
metode Software Development Life Cycle (SDLC) ICONIX yang secara presisi memetakan 
kebutuhan fungsional ke dalam perancangan berbasis objek. Arsitektur sistem dibangun 
menggunakan kerangka kerja Next.js pada sisi antarmuka dengan mekanisme Server-Side 
Rendering (SSR) untuk mempercepat pemuatan halaman, dipadukan dengan bahasa 
pemrograman Golang pada sisi peladen yang mengimplementasikan fitur konkurensi 
Goroutines untuk pemrosesan data asinkron secara paralel. Berdasarkan hasil pengujian 
yang dilakukan, sistem tervalidasi 100% pada seluruh skenario uji fungsionalitas fitur 
pelaporan dan analitik. Lebih lanjut, pengukuran performa arsitektur menunjukkan bahwa 
integrasi SSR dan optimasi konkurensi mampu meningkatkan kecepatan muat data metrik 
(Time-to-First-Byte) hingga 38% lebih efisien, serta mempertahankan stabilitas pemakaian 
sumber daya memori saat memproses volume log akses yang masif. Sebagai 
kesimpulannya, sistem MONIKA terbukti secara signifikan meningkatkan efisiensi 
operasional tim teknologi informasi dalam mendeteksi anomali secara dini dan 
memfasilitasi manajemen BPK RI dalam melakukan evaluasi kinerja aplikasi berbasis data 
analitik yang presisi.​

ABSTRACT 
The management of user activity log data on the BIDICS system within the Audit Board of 
the Republic of Indonesia (BPK RI) was previously in the form of raw textual data without 
analytical visualization support. This condition caused operational monitoring, traffic 
pattern identification, and anomaly detection processes to run inefficiently as they heavily 
relied on manual analysis. Furthermore, the absence of structured dashboard utilization 
comparison data caused the optimization process and managerial decision-making to not 
be fully based on measurable data. As a technical solution, the MONIKA (Monitoring 
Kluster Analitik) product was developed, which was a centralized single-view dashboard 
system designed to aggregate and visualize millions of rows of user interaction log data 
into dynamic strategic information. The software development was implemented using the 
ICONIX Software Development Life Cycle (SDLC) method, which precisely mapped 
functional requirements into object-oriented design. The system architecture was built 
using the Next.js framework on the interface side with a Server-Side Rendering (SSR) 
mechanism to accelerate page loading, combined with the Golang programming language 
on the server side which implemented Goroutines concurrency features for parallel 
asynchronous data processing. Based on the testing results, the system was 100% validated 
across all functional test scenarios for reporting and analytical features. Furthermore, the 
architecture's performance measurement showed that the integration of SSR and 
concurrency optimization improved metric data load speed (Time-to-First-Byte) by up to 
38% more efficiently, and maintained memory resource usage stability when processing 
massive access log volumes. In conclusion, the MONIKA system was proven to 
significantly improve the operational efficiency of the information technology team in 
detecting anomalies early and facilitated the management of BPK RI in evaluating 
application performance based on precise analytical data. 
 
Keywords : Dashboard, Golang, ICONIX, Monitoring, Next.js

1.1​
Latar Belakang Proyek 
Badan Pemeriksa Keuangan Republik Indonesia (BPK RI) terus beradaptasi 
dengan transformasi digital dalam sektor publik yang bergeser menuju pemanfaatan 
analisis data besar (Big Data Analytics). Sebagai wujud nyata dari upaya tersebut, BPK RI 
memiliki sistem BIDICS, yaitu sebuah platform yang memuat berbagai kluster dashboard 
analitik untuk menunjang aktivitas audit dan evaluasi kinerja. Keberadaan dashboard ini 
merupakan instrumen penting bagi pemangku kepentingan, seperti para auditor dan jajaran 
manajemen BPK RI, untuk memantau data strategis negara. 
Meskipun sistem BIDICS telah digunakan, terdapat permasalahan pada aspek pengelolaan 
data rekam jejak (log) aktivitas pengguna yang selama ini masih berupa data tekstual 
mentah tanpa adanya dukungan visualisasi analitik. Kondisi ini menyebabkan proses 
pemantauan kestabilan sistem, identifikasi pola trafik, dan deteksi potensi anomali menjadi 
sangat tidak efisien karena sangat bergantung pada proses analisis manual oleh tim 
Teknologi Informasi (TI). 
Hingga saat ini, mekanisme pemantauan (monitoring) untuk dashboard BIDICS masih 
berjalan secara terpisah dan belum terintegrasi ke dalam satu sistem yang terpusat. Selain 
itu, belum tersedianya data pembanding penggunaan dashboard yang terstruktur 
menyebabkan proses optimalisasi, sosialisasi ulang, dan evaluasi operasional belum 
sepenuhnya berbasis pada data yang terukur. 
Sebagai solusi atas permasalahan tersebut, diusulkan pengembangan produk MONIKA 
(Monitoring Kluster Analitik). MONIKA adalah sebuah sistem single view dashboard 
terpusat yang secara khusus dirancang untuk mengolah dan memvisualisasikan data log 
pengguna menjadi informasi yang mudah dipahami oleh manajemen. Sistem ini 
diharapkan mampu memvisualisasikan insight interaktif seperti statistik login, riwayat 
aktivitas, dan pola penggunaan kluster dashboard untuk memfasilitasi tim TI maupun 
manajemen BPK RI dalam melakukan deteksi anomali secara proaktif dan mengevaluasi 
kinerja aplikasi secara presisi.

2.2​
Konsep 
Konsep utama dalam proyek MONIKA mencakup sistem informasi 
monitoring, pengelolaan log aktivitas pengguna, analitik data operasional, dashboard 
visualisasi, rekayasa kebutuhan, serta pendekatan pengembangan perangkat lunak berbasis 
SDLC ICONIX. Konsep-konsep tersebut diperlukan karena MONIKA diposisikan sebagai 
sistem single view dashboard yang mengolah data log pengguna BIDICS menjadi 
informasi pemantauan yang lebih mudah dipahami oleh tim TI dan manajemen BPK RI. 
Dengan demikian, pembahasan pada bagian ini tidak menjelaskan rancangan teknis 
MONIKA secara spesifik, melainkan menjelaskan dasar teoretis yang mendukung 
pemilihan solusi pemantauan berbasis dashboard dan data log.  
2.2.1​ Sistem Informasi Monitoring

2.2.6​ SDLC dan ICONIX Process  
Software Development Life Cycle atau SDLC merupakan pendekatan siklus

mencakup evolusi suatu sistem, produk, layanan, atau proyek dari konsepsi hingga 
penghentian penggunaannya. Dalam pengembangan perangkat lunak, fase pengembangan
