2.4.1.​ Next.js 
Next.js merupakan framework berbasis React yang digunakan pada sisi 
frontend untuk membangun aplikasi web. Dalam proyek MONIKA, Next.js relevan karena 
sistem yang dikembangkan berbentuk dashboard web yang membutuhkan tampilan 
antarmuka responsif, pemuatan data dinamis, dan integrasi dengan layanan backend.

Konsep Server-Side Rendering atau SSR menjadi salah satu alasan pemilihan 
Next.js. Pada pendekatan SSR, sebagian proses pembentukan halaman dilakukan di sisi

getServerSideProps berjalan di server, mengembalikan data JSON, dan data tersebut 
digunakan untuk merender HTML awal halaman. 
Next.js juga berhubungan erat dengan React sebagai pustaka pembangun 
antarmuka. React menyediakan konsep component-based interface, sehingga bagian

komponen yang terpisah dan dapat digunakan kembali. Dokumentasi React menjelaskan 
bahwa hooks memungkinkan komponen menggunakan fitur React, misalnya state untuk 
menyimpan masukan pengguna dan effect untuk menyinkronkan komponen dengan sistem 
eksternal. Konsep ini relevan untuk fitur dashboard yang membutuhkan filter tanggal, 
pembaruan visualisasi, dan pengambilan data dari API. 
Selain React, penggunaan TypeScript pada ekosistem Next.js dapat
